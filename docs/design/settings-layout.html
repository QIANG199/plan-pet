交互

进入BOOT 双击；进入时暂停桌宠帧动画，网络轮询后台继续
扫描进入自动扫 + 「重新扫描」；扫描中列表显示 shimmer 占位、按钮图标旋转
连接按钮转圈 ≤15s → 成功绿 ✓ 600ms 自动收起并存 NVS → 失败输入框抖动+红边+文案，旧凭据自动回连
保存返回值有变化才可点；点击保存 → 回桌面并触发重连
返回键键盘页 ✕ = 回主设置；主设置「返回」= 回桌面（未保存改动丢弃）
首跑引导无凭据时桌面 WiFi 图标旁闪烁「Setup: double-click BOOT」10px 提示

配色与字体

深色底 #000000｜卡 #000000 + 边 #2a303c｜墨 #e8ecf3｜次 #9aa3b2｜强调绿 #22c55e
浅色底 #e9edf2｜卡 #ffffff｜墨 #1c2430｜次 #5a6575
字体拉丁/数字 montserrat 12/14；中文用项目生成字体 font_cn_16（等线 16px 子集，ASCII + 项目用字）
主题联动设置页跟随深/浅主题即时切换；BOOT 短按换肤在设置页内同样生效
备注：① v1.1 起小控件均带 +4~5px 隐形扩展点击区，页面示意图为早期比例、尺寸以规格表为准；② 中文渲染依赖 font_cn_16（约 86KB，等线子集）：新增中文文案必须用 lv_font_conv 重新生成（命令见 firmware/src/ui/font_cn_16.h），否则缺字显示「口」；③ 扫描在 STA 连接态做会短暂跳信道，属正常现象；④ 卡片禁用 clip_corner（圆角裁剪 + 列表溢出曾触发渲染风暴导致看门狗复位），列表用滚动收纳溢出。
